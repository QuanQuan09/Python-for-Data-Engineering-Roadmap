# Week 5 – Business Reporting with Pandas

## Overview

Week 5 focused on transforming operational data into meaningful business reports using Pandas. This week introduced reporting workflows commonly used by Data Engineers and Operations teams, including grouped summaries, pivot tables, datetime processing, KPI creation, and automated report exports.

## Topics Covered

- Filtering and summarizing operational data
- GroupBy and named aggregations
- Advanced aggregations
- Pivot tables
- Datetime conversion and processing
- Timedelta calculations
- Business KPI creation
- CSV exports
- Excel workbook generation
- Text report generation
- File validation

## Mini Project

### Automated Operations Reporting Pipeline

Built an end-to-end reporting pipeline that:

- Processed enterprise incident data
- Calculated SLA breach metrics
- Identified high CPU incidents
- Generated team, environment, daily operations, and priority reports
- Exported reports to CSV
- Generated a multi-sheet Excel dashboard
- Created a text-based executive summary
- Validated exported reports
- Implemented timestamped filenames for report versioning
